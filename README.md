# Next.js Project Setup

This project was created using Next.js with the `create-next-app` tool.

## Getting Started

To start the application, open your terminal and run the following command:

```bash
npm run dev
```

After starting the development server, open your web browser and visit [http://localhost:3000](http://localhost:3000) to view the application.

You can make changes to the website by editing the `app/page.tsx` file. Any changes you save will automatically appear in the browser.

This project also uses `next/font` to manage and optimise fonts. The Geist font family, developed for Vercel, is used to enhance the application's appearance.
